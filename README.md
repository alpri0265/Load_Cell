# Load Cell 2000

Ваговий модуль на базі тензодатчика (load cell) 2000 кг: Arduino Nano, HX711, LCD2004 (I2C) та керування меню через поворотний енкодер EC11.

## Можливості

- Вимірювання ваги з фільтрацією сигналу (ковзне середнє) та індикатором стабільності показника.
- Меню на LCD2004, повне керування одним енкодером (обертання / клік / довге утримання).
- Тарування — швидке (утримання кнопки) і через меню.
- Майстер калібрування з еталонною вагою, коефіцієнт зберігається в EEPROM.
- Перемикання одиниць виміру kg / g.

## Апаратура

| Компонент | Призначення |
|---|---|
| Тензодатчик 2000 кг + HX711 | Вимірювання ваги |
| Arduino Nano | Керуючий контролер |
| LCD2004 (I2C, PCF8574) | Індикація |
| Енкодер EC11 (модуль `5V-KEY-S2-S1-GND`) | Керування меню |

Повна розводка пінів, схема живлення та BOM — у [PLAN.md](PLAN.md).

## Збірка та заливка

Проект на [PlatformIO](https://platformio.org/).

```
pio run              # зібрати
pio run -t upload    # залити на Nano
```

Бібліотеки (`HX711`, `LiquidCrystal_I2C`, `EEPROM`) підтягуються автоматично за `platformio.ini` при першому відкритті проекту.

## Структура прошивки

```
src/
├── Config.h          — піни та константи
├── main.cpp          — setup()/loop()
├── EncoderModule.*    — квадратурний декодер EC11 + кнопка
├── ScaleModule.*      — HX711: фільтрація, тарування, калібрування
├── DisplayModule.*    — обгортка LCD2004 (I2C)
├── StorageModule.*    — збереження калібрування в EEPROM
└── MenuModule.*       — стан-машина інтерфейсу
```
