# Інструкція з експлуатації та налаштування

Ваговий модуль: тензодатчик 2000 кг + HX711 + Arduino Nano + LCD2004 (I2C) + енкодер EC11.

## 1. Підключення живлення

- Живлення — стабілізований блок 5В, підключений на пін **`5V`** Arduino Nano (не `VIN`).
- **Не підключайте одночасно USB від комп'ютера і зовнішній блок живлення** — два джерела на лінії `5V` конфліктують між собою.
- Після подачі живлення пристрій ініціалізується протягом ~1–2 секунд (спочатку дисплей, потім опитування датчика) і показує головний екран.

## 2. Головний екран

```
      LOAD CELL
  123.4 kg   [OK]
  
Hold=Tare Clk=Menu
```

- Перший рядок — заголовок.
- Другий рядок — поточна вага, одиниці виміру, індикатор стабільності:
  - `[OK]` — показник стабільний (не змінюється більше ~500 мс).
  - `[..]` — показник ще змінюється/нестабільний.
- Нижній рядок — підказка керування.

## 3. Керування енкодером

| Дія | Результат |
|---|---|
| Обертання за годинниковою | Рух курсору/збільшення значення |
| Обертання проти годинникової | Рух курсору/зменшення значення |
| Коротке натискання (клік) | Вибір/підтвердження, вхід у меню з головного екрана |
| Довге утримання (>0.8с) | На головному екрані — швидке тарування (обнулення ваги); у меню/підменю — вихід/скасування, повернення на крок назад |

## 4. Меню

Вхід у меню — клік на головному екрані. Пункти (кожен на своєму рядку LCD):

```
> Tare
  Calibrate
  Units
  Exit
```

Обертанням переміщуєте курсор `>`, кліком — обираєте пункт.

### Tare
Миттєве обнулення ваги (аналог довгого утримання на головному екрані). Виконуйте з порожньою платформою.

### Calibrate — майстер калібрування
Покрокова процедура, потрібна після монтажу датчика і після заміни/зсуву платформи:

1. **Крок 1/2** — `"Remove all weight / from platform"`. Зніміть усе з платформи, клік → пристрій виконує тарування (нуль).
2. **Крок 2/2** — `"Place known weight / on platform"`. Покладіть еталонну вагу (бажано ≥30% від максимального діапазону, наприклад 500–1000 кг для датчика 2000 кг — чим більша еталонна вага, тим точніше калібрування), клік → пристрій зчитує сирі показники.
3. **Введення ваги еталону** — `">> X.X kg <<"`. Обертанням встановіть точне значення вашої еталонної ваги (крок 0.5 кг), клік → підтвердити.
4. Екран `"Calibration saved!"` — коефіцієнт калібрування записано в EEPROM, пристрій автоматично повертається на головний екран.

Калібрування зберігається постійно (EEPROM) і не втрачається при відключенні живлення.

### Units
Перемикання одиниць виміру між `kg` та `g`. Обертанням оберіть, клік — зберегти й повернутися в меню.

### Exit
Повернення на головний екран без змін.

## 5. Налаштування прошивки (для розробника)

Усі параметри зібрані в одному файлі — [src/Config.h](src/Config.h). Змінювати можна без переробки решти коду, після зміни потрібно перезалити прошивку (`pio run -t upload`).

| Параметр | Що означає | Коли змінювати |
|---|---|---|
| `PIN_HX711_DOUT`, `PIN_HX711_SCK` | Піни підключення HX711 | Якщо змінили розводку |
| `PIN_ENC_S1`, `PIN_ENC_S2`, `PIN_ENC_KEY` | Піни енкодера | Якщо змінили розводку (S1/S2 мають бути на пінах з апаратним перериванням — D2/D3 на Nano) |
| `LCD_I2C_ADDRESS` | I2C-адреса дисплея | Якщо екран не оживає на `0x27` — спробуйте `0x3F` |
| `HX711_SAMPLES_AVG` | К-сть зчитувань при калібруванні | Збільшити для точнішого, але повільнішого калібрування |
| `WEIGHT_FILTER_SIZE` | Розмір ковзного середнього на головному екрані | Збільшити — плавніші, але інерційніші покази |
| `STABLE_THRESHOLD_KG` | Поріг для індикатора `[OK]` | Зменшити для суворішої вимоги стабільності |
| `STABLE_TIME_MS` | Час утримання в порозі для `[OK]` | Збільшити, щоб `[OK]` з'являлось повільніше, але надійніше |
| `BUTTON_DEBOUNCE_MS` | Дебаунс кнопки KEY | Збільшити, якщо клік іноді "двоїться" |
| `BUTTON_LONGPRESS_MS` | Поріг довгого утримання | Змінити тривалість утримання для швидкого тарування/виходу |
| `HX711_READY_TIMEOUT_MS` | Максимальний час очікування готовності HX711 | Збільшити, якщо ваш БЖ повільно виходить на робочу напругу і пристрій не встигає ініціалізувати датчик за 2с |
| `DEFAULT_SCALE_FACTOR` | Початковий калібрувальний коефіцієнт (до першого калібрування) | Зазвичай не чіпати — калібрування перезапише його в EEPROM |

## 6. Заливка/перепрошивка

Проект — PlatformIO (`platformio.ini`), відкривається у VSCode з розширенням PlatformIO.

1. Відкрити папку `Load_Cell` у VSCode.
2. Дочекатись, поки PlatformIO встановить платформу `atmelavr` і бібліотеки (`HX711`, `LiquidCrystal_I2C`, `EEPROM`) — відбувається автоматично при першому відкритті.
3. Підключити Nano по USB, перевірити правильний COM-порт (див. розділ 7).
4. Виконати **PlatformIO: Upload** (або в терміналі: `pio run -t upload`).
5. **Не запускайте кілька задач PlatformIO одночасно** (Build і Upload разом) — це спричиняє помилку `ar.exe: unable to rename ... File exists`. Дочекайтесь завершення однієї задачі перед запуском наступної.

## 7. Типові несправності

| Симптом | Причина | Рішення |
|---|---|---|
| На LCD суцільні чорні квадрати замість тексту | Неправильно виставлений контраст | Покрутити підстроювальний резистор на I2C-платі дисплея |
| LCD взагалі порожній, не оживає | Невірна I2C-адреса або обрив SDA/SCL | Спробувати адресу `0x3F` замість `0x27` у `Config.h`; перевірити проводку |
| При живленні рівно 5В екран довго/взагалі не запускається, а при заниженій напрузі — нормально | HX711 не встигає стабілізуватись при подачі живлення (без таймауту прошивка «висла» б назавжди) | Уже виправлено — додано таймаут `HX711_READY_TIMEOUT_MS = 2000` мс. Якщо все ще довго — поставити конденсатор 100–470 мкФ на вхід живлення HX711/Nano, перевірити якість БЖ |
| `avrdude: stk500_recv(): programmer is not responding` при заливці | Невідповідність швидкості бутлоадера | `board = nanoatmega328new` (115200 бод) для сучасних клонів з Optiboot; `board = nanoatmega328` (57600 бод) для старих |
| `could not open port 'COMx'` при заливці | COM-порт змінився (перепідключення USB) | Виконати `pio device list`, знайти актуальний порт (`USB-SERIAL CH340`), виправити `upload_port`/`monitor_port` у `platformio.ini` |
| `UnknownPackageError` при першій збірці бібліотеки | Невірно вказаний автор бібліотеки в `lib_deps` | Використовувати `marcoschwartz/LiquidCrystal_I2C`, а не `johnrickman/...` |
| `ar.exe: unable to rename ... File exists` при збірці | Дві задачі PlatformIO пишуть у одну папку збірки одночасно | `pio run -t clean`, потім зібрати ще раз, не запускаючи кілька задач паралельно |
| Показ ваги "стрибає"/шумить | Електричні завади на сигнальному кабелі датчика, нестабільне живлення | Використати екранований кабель, рознести сигнальні і силові проводи, додати конденсатор по живленню HX711 |
| Енкодер пропускає кроки або крутиться в інший бік | Брязкіт контактів / неякісний модуль / неправильна розводка S1/S2 | Перевірити, що S1→D2, S2→D3 (обидва на апаратних перериваннях); за потреби збільшити фільтрацію в `EncoderModule.cpp` |
